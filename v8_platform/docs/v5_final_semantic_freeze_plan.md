requirement documents remain unchanged and authoritative. `FAIL_FIRST` means a
V4 counterexample was reproduced; `VERIFIED_EXISTING_BEHAVIOR` is used only
when the new requirement-level test already passed without an implementation
change; `VERIFIED` requires the runtime path and all relevant tests to pass.

## Freeze policy

- No attack/normal truth is accepted as an online model input.
- C model output is advisory; all action admission and targeting remain B-owned.
- Missing measurements are represented by `null` plus availability, never a
  fabricated zero.
- Formal SKG/terminal root of trust, trained C models, real IQ and approved real
  calibration remain external deliverables and cannot be promoted by mock tests.
