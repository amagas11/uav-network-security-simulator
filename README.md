## 正式场景

报文伪装与遥测数据篡改均由 External 捕获真实合法报文后额外注入攻击副本，原件仍正常传输；分别修改声明身份和遥测业务内容，原 HMAC 不重算。DoS 为应用层报文洪泛；窃听为被动捕获与敏感业务保密保护；重放原样重发已捕获合法报文。

正式前端显式使用专项检测配置：只有 DoS 启用 Flooding 告警，基础 HMAC 与重放安全处理保留。旧 API 未提供开关时保持综合检测。未启用检测器的性能为 N/A。

DoS目标及全网双评价保持V21定义，GCS次生告警完整保留。目标正常样本不足仍为N/A。本轮仅修复认证失败累计、布尔和缺失值显示，并删除趋势提示与共享Footer；不改变检测规则、阈值或发包逻辑。

源码校验以 `SOURCE_MANIFEST_V21_FINAL.json` 为准；本轮记录、截图、测试及评价复算见 `V21_FINAL_VERIFICATION.zip`。历史清单不能用于本版验收。
